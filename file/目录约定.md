# file/ 目录约定

## 用途

存放**部署编排文件与数据库初始化脚本**，不存放文档（文档归 `docs/` 目录）。

## 应存放的文件类型

| 类型 | 说明 | 示例 |
|------|------|------|
| Docker 部署编排 | 基础设施/服务容器编排 | docker-compose-infra.yml |
| 数据库初始化 SQL | 建库、建表、预置数据 | ledger_init.sql |

## 命名规范

- 部署编排：`docker-compose-<用途>.yml`（当前唯一：`docker-compose-infra.yml`）
- SQL：`<模块>_init.sql`，或按用途分子目录（如 `mysql-init/init.sql`）

## 当前文件

| 文件 | 功能 |
|------|------|
| `docker-compose-infra.yml` | 基础设施编排（MySQL 3307 + Nacos v3.2.3 内置存储） |
| `mysql-init/init.sql` | 建 3 库（hakira_nacos / hakira_auth / hakira_ledger） |
| `hakira_auth_init.sql` | auth 库初始化（`hakira_user` 表 + 预置 admin，BCrypt 哈希） |
| `ledger_init.sql` | ledger 库建表（会计科目 + 分录头/行 + 库存流水/快照） |

## 注意事项

- 历史版本/备份文件勿保留在本目录，直接删除（git 可回溯）
- 含明文凭据的调试产物（如 nacos-application.properties）不入库

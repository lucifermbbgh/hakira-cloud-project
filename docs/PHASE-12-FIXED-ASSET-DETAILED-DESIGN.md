# PHASE-12 固定资产管理 — 详细设计

> **版本：** v1.0 · 2026-08-15
> **前置：** PHASE-12-FIXED-ASSET-DESIGN.md

## 一、数据模型（新增 1 张表）

`fixed_asset`：资产卡片，含原值、残值率、折旧年限、折旧方法、累计折旧、净值、
状态（IN_USE/DISPOSED）、version 乐观锁。

## 二、核心实现

### 2.1 折旧方法
| 方法 | 公式 | 示例（原值 12000，残值率 0.05，120 月） |
|------|------|------|
| 直线法 | 原值×(1−残值率)/月数 | 12000×0.95/120 = 95/月 |
| 双倍余额递减 | 净值×2/月数 | 12000×2/120 = 200/月（首月） |

净额不低于残值：净值 − 月折旧 < 残值 时，月折旧 = 净值 − 残值（提到残值即止）。

### 2.2 折旧计提（depreciate）
遍历 IN_USE 资产 → 计算月折旧 → 生成折旧凭证（借 6602 管理费用 / 贷 1602 累计折旧）
→ 乐观锁更新累计折旧 + 净值。已提足（月折旧 ≤ 0）跳过。

### 2.3 资产处置（dispose）
生成清理凭证（借 1602 累计折旧 + 借 6711 营业外支出净值 / 贷 1601 固定资产原值）
→ 状态置 DISPOSED（乐观锁）。

## 四、关键坑与教训

1. **BigDecimal 除法需指定舍入**：折旧额计算 `divide` 必须带 `RoundingMode.HALF_UP`，
   否则可能除不尽抛 ArithmeticException。

2. **折旧凭证日期 = 期间末日**：保证折旧凭证落在目标期间分区（与结转凭证同款处理）。

3. **处置凭证借贷平衡**：借 累计折旧 + 借 净值（营业外支出）= 贷 原值，
   因为 累计折旧 + 净值 = 原值，天然平衡。

4. **折旧表字段覆盖**：`/asset/list` 返回原值/累计折旧/净值，已覆盖固定资产折旧表
   的核心字段（月折旧额可由原值×折旧率推导）。

## 一、阶段目标

预算编制、预算执行监控、预算差异分析。

| 功能 | 说明 |
|------|------|
| 预算编制 | 按期间 + 科目设置预算金额 |
| 执行监控 | 实际发生额 vs 预算金额 |
| 差异分析 | 差异 = 实际 − 预算，超支/结余标识 |

---

## 二、核心概念

### 2.1 预算维度
按会计期间（YYYYMM）+ 科目编码（subject_code）编制预算，一期一科目一预算金额。

### 2.2 实际发生额方向
| 科目方向 | 实际发生额 |
|---------|-----------|
| 借方（D，费用类） | 借 − 贷（净借方） |
| 贷方（C，收入类） | 贷 − 借（净贷方） |

### 2.3 差异
`差异 = 实际 − 预算`；费用类差异 > 0 = 超支，收入类差异 < 0 = 未达标。

---

## 三、数据模型（新增 1 张表）

### budget（预算表）
| 字段 | 类型 | 说明 |
|------|------|------|
| period + subject_code | — | 复合主键（期间 + 科目） |
| budget_amount | decimal(18,2) | 预算金额 |
| version | int | 乐观锁 |

---

## 四、功能设计

### 4.1 预算编制（POST /budget/set）
按期间 + 科目设置/更新预算金额（upsert + 乐观锁）。

### 4.2 执行监控（GET /budget/query?period=YYYYMM）
返回每科目的预算金额 + 实际发生额 + 差异 + 超支/结余标识。

### 4.3 差异分析（GET /budget/variance?period=YYYYMM）
汇总差异，输出超支科目明细。

## 五、接口设计

| 方法 | 路径 | 说明 |

| POST | /budget/set | 编制/更新预算 |

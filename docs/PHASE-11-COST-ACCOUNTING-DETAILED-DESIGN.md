# PHASE-11 成本核算 — 详细设计

## 一、数据模型（复用辅助核算框架，不新建表）

成本项目（料工费）复用 Phase 7 辅助核算：
- 维度 `COST_ITEM`，值 `DM` 直接材料 / `DL` 直接人工 / `MO` 制造费用
- 成本归集分录的 5001/5101 行挂 COST_ITEM 维度

## 二、核心实现

### 2.1 制造费用分配（allocateOverhead）
1. 期间校验（OPEN 才能分配）
2. 聚合 5101 制造费用净额（借 - 贷），净额 ≤ 0 则报错（无费用可分配 / 已分配）
3. 生成分配凭证（entry_date = 期间末日，自动编号）：借 5001(MO) / 贷 5101
4. 分配凭证的 5001 行挂 `COST_ITEM=MO`

### 2.2 成本计算单（getCostSheet）
聚合 `5001` 生产成本按 COST_ITEM 维度，净额 = 借 - 贷：
- DM 直接材料、DL 直接人工、MO 制造费用，总成本 = DM + DL + MO

## 四、关键坑与教训

1. **成本计算单聚合 5001 而非 5101**：制造费用归集分录记在 5101（挂 MO），
   但成本计算单聚合的是 5001。只有「制造费用分配」把 5101 转到 5001(MO) 后，
   制造费用才计入成本计算单。这是成本流转的本质：归集在 5101，分配后进 5001。

2. **分配幂等靠余额判断**：5101 归零后再次分配报错（净额 ≤ 0），天然防重复分配。

3. **料工费依赖辅助核算**：成本项目区分完全靠 COST_ITEM 维度，若无维度则无法
   区分料工费——再次验证 Phase 7 辅助核算框架的扩展性（现金流量表用 CASH_FLOW，
   成本核算用 COST_ITEM，同一框架复用）。

# docs/ 目录约定

## 用途

存放**项目文档**，不存放部署文件、配置文件、脚本、SQL 等（这些归 `file/` 目录）。

## 应存放的文档类型

| 类型 | 说明 | 命名 |
|------|------|------|
| 总体设计文档 | 架构、功能、目标、技术栈、阶段路线 | `ARCHITECTURE.md` |
| 接口文档 | API 功能、参数、返回值、错误码 | `API-DOCUMENT.md` |
| 阶段设计文档 | 每阶段要完成什么 | `PHASE-N-主题-DESIGN.md` |
| 详细设计文档 | 功能细节、表结构、实现 | `PHASE-N-主题-DETAILED-DESIGN.md` |
| 测试报告 | 测试目标、结果、问题、处理 | `PHASE-N-主题-TEST-REPORT.md` |

## 命名规范

- 总体/接口文档：固定名 `ARCHITECTURE.md`、`API-DOCUMENT.md`
- 阶段文档：`PHASE-N-<主题>-<类型>.md`，类型取 `DESIGN` / `DETAILED-DESIGN` / `TEST-REPORT`
- 每个阶段三份文档配套生成，测试报告合并该阶段完整记录（不留独立的历史报告文件）

# docs/ 目录约定

## 用途

存放**项目文档**，不存放部署文件、配置文件、脚本、SQL 等（这些归 `file/` 目录）。

## 应存放的文档类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 设计文档 | 架构设计、模块设计 | 会计账簿微服务架构设计 |
| 详细设计文档 | 表结构、接口实现细节、算法 | 分录表分区与乐观锁设计 |
| 接口文档 | API 说明、参数/返回值 | 分录/库存接口说明 |
| 测试文档 | 冒烟测试、验证报告、问题记录 | 基础设施部署与冒烟测试报告 |

## 命名规范

建议格式：`YYYY-MM-DD-文档主题.md`

- 日期前缀便于按时间归档
- 主题用中文或英文短横线连接

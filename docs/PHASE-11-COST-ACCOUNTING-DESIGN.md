# PHASE-11 成本核算 — 设计文档

> **版本：** v1.0 · 2026-08-15
> **阶段：** Phase 11（依赖 Phase 7 科目体系 + 辅助核算 + Phase 9 结账）
> **模块：** hakira-ledger-entry（账务域）

---

## 一、阶段目标

成本归集与分配：料（材料）、工（人工）、费（制造费用）归集到生产成本，
制造费用分配，输出成本计算单。

| 功能 | 说明 |
|------|------|
| 成本项目维度 | 料/工/费三项目（COST_ITEM 辅助核算） |
| 成本归集 | 材料/人工/制造费用分录挂成本项目维度 |
| 制造费用分配 | 5101 制造费用余额分配到 5001 生产成本 |
| 成本计算单 | 聚合生产成本按成本项目，输出总成本 |

---

## 二、核心概念

### 2.1 成本项目（料工费）
| 维度值 | 项目 | 归集来源 |
|--------|------|---------|
| DM | 直接材料 | 原材料领用（1403 → 5001） |
| DL | 直接人工 | 工资计提（2211 → 5001） |
| MO | 制造费用 | 间接费用归集 + 分配（5101 → 5001） |

### 2.2 成本流转
```
原材料 1403 ──领用──> 生产成本 5001(DM)
应付薪酬 2211 ──计提──> 生产成本 5001(DL)
间接费用 ──归集──> 制造费用 5101(MO) ──分配──> 生产成本 5001(MO)
生产成本 5001 ──完工──> 库存商品 1405
```

---

## 三、数据模型

**新增辅助核算维度**（复用 Phase 7 辅助核算框架，不新建表）：
- 维度 `COST_ITEM`（成本项目），预置值：`DM` 直接材料、`DL` 直接人工、`MO` 制造费用
- 成本归集分录的 5001/5101 行挂 COST_ITEM 维度，成本计算单按此聚合

---

## 四、功能设计

### 4.1 制造费用分配（POST /cost/allocate-overhead）
1. 聚合 5101 制造费用本期余额（借方净额）
2. 生成分配凭证：借 5001 生产成本（挂 COST_ITEM=MO），贷 5101 制造费用
3. 分配后 5101 余额归零，5001 增加制造费用

### 4.2 成本计算单（GET /cost/cost-sheet）
聚合 5001 生产成本本期发生额，按 COST_ITEM 维度分类：
- 直接材料 = DM 发生额、直接人工 = DL 发生额、制造费用 = MO 发生额
- 总成本 = DM + DL + MO

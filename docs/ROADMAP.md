## 三、各阶段详细规划

### Phase 6：大数据分析层（Flink + Spark）

- **目标**：流式 + 批式分析会计流水，形成数据洞察能力
- **内容**：
  - Flink 流式：实时科目余额监控、异常分录实时告警、实时流水统计
  - Spark 批式：离线对账、报表数据预聚合、历史趋势分析
- **关键任务**：
  1. Flink CDC 读取 MySQL 分录/流水
  2. 实时余额计算算子
  3. Spark 批处理 Job（对账 / 预聚合）
  4. 分析结果输出
- **产出**：flink/spark 模块可运行的分析任务

### Phase 7：会计科目与辅助核算体系

- **目标**：完善科目体系 + 引入辅助核算维度
- **内容**：完整企业会计准则科目表（当前仅 21 个核心科目）、明细科目层级、辅助核算维度（部门/项目/客户/供应商/现金流量）
- **关键任务**：
  1. 科目表扩展（完整科目 + 层级结构）
  2. 辅助核算维度表设计
  3. 分录行关联辅助核算维度
- **产出**：完整科目字典 + 辅助核算维度

### Phase 8：凭证管理深化（审核/冲销/红字）

- **目标**：凭证全生命周期管理
- **内容**：凭证审核流（关联 Phase 3 审批流）、冲销、红字凭证、凭证号规则、凭证附件
- **关键任务**：
  1. 凭证审核流程对接审批流
  2. 冲销 / 红字逻辑
  3. 凭证号自动编号规则
  4. 凭证状态机扩展（DRAFT→POSTED→REVERSED）
- **产出**：凭证从录入到审核的全流程

### Phase 9：期末结账与账务结转

- **目标**：期末账务处理自动化
- **内容**：损益类科目结转（收入/成本/费用→本年利润）、月结/年结流程、试算平衡表、科目余额表
- **关键任务**：
  1. 损益结转（自动生成结转凭证）
  2. 月结/年结流程（结账状态锁定）
  3. 试算平衡表生成
  4. 科目余额表（期初/本期发生/期末）
- **产出**：一键结账 + 余额/试算平衡

### Phase 10：财务报表体系（三大报表）

- **目标**：输出三大财务报表
- **内容**：资产负债表（资产=负债+权益）、利润表（收入-成本-费用）、现金流量表（经营/投资/筹资）
- **关键任务**：
  1. 资产负债表生成
  2. 利润表生成
  3. 现金流量表生成（直接法/间接法）
- **产出**：三大报表查询接口 + 报表数据模型

### Phase 11：成本核算

- **目标**：成本归集与分配
- **内容**：材料成本归集、生产成本归集分配（料工费）、成本计算单
- **关键任务**：
  1. 材料成本归集
  2. 生产成本归集与分配
  3. 成本计算单生成
- **产出**：成本核算模块

### Phase 12：固定资产管理

- **目标**：固定资产全生命周期
- **内容**：资产卡片、折旧计提（直线法/加速折旧）、资产处置/报废
- **关键任务**：
  1. 资产卡片管理
  2. 折旧计提（自动生成折旧凭证）
  3. 资产处置 / 报废
- **产出**：固定资产模块

### Phase 13：应收应付与往来账龄

- **目标**：往来核算与账龄管理
- **内容**：客户/供应商往来、账龄分析、应收预警/催收
- **关键任务**：
  1. 往来单位管理
  2. 账龄分析（按账期分段）
  3. 应收预警 / 催收提醒
- **产出**：往来核算模块

### Phase 14：存货核算与计价

- **目标**：存货成本核算
- **内容**：存货计价（先进先出/加权平均）、存货盘点、出库成本结转
- **关键任务**：
  1. 存货计价方法实现（FIFO / 加权平均）
  2. 存货盘点（盘盈盘亏）
  3. 出库成本自动结转
- **产出**：存货核算模块

### Phase 15：预算管理

- **目标**：预算编制与执行监控
- **内容**：预算编制（按科目/部门/项目）、预算执行监控、预算差异分析
- **关键任务**：
  1. 预算编制
  2. 预算执行监控（实际 vs 预算）
  3. 预算差异分析
- **产出**：预算管理模块

### Phase 16：审计合规与系统治理

- **目标**：审计追溯与系统治理
- **内容**：审计日志（操作审计）、数据追溯（凭证→分录→流水）、权限细化（RBAC）、多租户（可选）
- **关键任务**：
  1. 操作审计日志
  2. 数据全链路追溯
  3. RBAC 权限细化
  4. 多租户隔离（可选）
- **产出**：审计 + 治理能力

## 四、阶段优先级建议

| 优先级 | 阶段 | 理由 |
|--------|------|------|
| P0 | Phase 6（大数据） | 已完成路线终点，先收尾 |
| P0 | Phase 7（科目体系） | 会计业务深化的地基，几乎所有后续阶段依赖 |
| P1 | Phase 8（凭证管理） | 凭证是账务核心，审核/冲销是刚需 |
| P1 | Phase 9（结账） | 结账是报表前置 |
| P1 | Phase 10（报表） | 三大报表是会计系统核心价值输出 |
| P2 | Phase 11-14 | 成本/资产/往来/存货，相对独立可并行 |
| P2 | Phase 15（预算） | 依赖报表 + 科目 |
| P3 | Phase 16（审计） | 横切关注点，可随各阶段渐进建设 |

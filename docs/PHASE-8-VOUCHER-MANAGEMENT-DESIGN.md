## 三、设计要点

### 3.1 凭证状态机

```
DRAFT(草稿) ──提交──> PENDING(待审) ──通过──> POSTED(已记账)
   ▲                     │
   │退回                  │驳回
   └─────────────────────┘
POSTED ──冲销──> REVERSED(已冲销)
POSTED ──作废──> VOID(已作废)
```

| 状态 | 含义 | 可操作 |
|------|------|--------|
| DRAFT | 草稿 | 编辑/删除/提交审核 |
| PENDING | 待审核 | 通过/驳回 |
| POSTED | 已记账 | 冲销/作废 |
| REVERSED | 已冲销 | 只读 |
| VOID | 已作废 | 只读 |

### 3.2 冲销 / 红字

**冲销（Reversal）**：对已 POSTED 分录生成一笔**反向分录**（借贷金额互换、负数红字），并**复制辅助核算维度**（Phase 7 已支持查询返回 aux）。

```
原分录：借 管理费用 500 / 贷 银行存款 500
冲销分录：借 银行存款 500 / 贷 管理费用 500（红字），原分录状态 → REVERSED
```

### 3.3 凭证号自动编号规则

`PZ-YYYYMMDD-NNN`（PZ + 日期 + 当日 3 位流水号），未传 voucherNo 时自动生成。

### 3.4 审核流（对接 Phase 3 Flowable）

凭证提交审核 → 关联 Flowable 审批流 → 通过后状态变 POSTED / 驳回退回 DRAFT。

## 四、执行步骤

```
步骤1：凭证状态机字段 + 状态枚举（DRAFT/PENDING/POSTED/REVERSED/VOID）
步骤2：冲销接口（生成反向分录 + 复制辅助核算 + 原分录置 REVERSED）
步骤3：凭证号自动编号（PZ-YYYYMMDD-NNN）
步骤4：审核流对接（提交/通过/驳回）
步骤5：验证（状态机流转 + 冲销 + 自动编号）
```

## 五、阶段验收标准

- [ ] 冲销生成反向分录（含辅助核算复制）
- [ ] 凭证号自动编号
- [ ] 审核流对接

3. **冲销范围**：冲销只做单笔整单冲销，还是支持部分冲销（单行冲销）？

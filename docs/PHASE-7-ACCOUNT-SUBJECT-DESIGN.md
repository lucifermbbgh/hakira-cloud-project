# hakira-cloud-project — Phase 7 会计科目与辅助核算体系方案设计

> **阶段：** Phase 7 · 会计科目与辅助核算体系
> **状态：** 📋 设计中
> **定位：** 会计业务深化地基（几乎所有后续阶段依赖）

---

## 一、阶段目标

在 Phase 5 的 21 个核心科目基础上，完善为**完整企业会计准则科目体系**（含层级），并引入**辅助核算维度**（部门/项目/客户/供应商/现金流量），为凭证管理、结账、报表、成本核算等后续阶段提供科目与核算地基。

## 二、现状

| 项 | 现状 |
|----|------|
| account_subject | 21 个核心科目（资产6/负债3/权益3/成本2/损益7），字段含 category、balance_direction |
| journal_entry_line | 有 subject_code 关联科目，但**无辅助核算字段** |
| 科目层级 | 无 parent_code，不支持明细科目 |

## 三、设计要点

### 3.1 科目体系扩展

#### 3.1.1 表结构扩展

`account_subject` 新增字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| parent_code | varchar(20) | 上级科目编码（NULL=一级科目） |
| subject_level | tinyint | 科目级次（1=一级，2=二级…） |

#### 3.1.2 完整一级科目（约 80 个）

按《企业会计准则——应用指南》扩充，当前 21 → 约 80 个一级科目：

| 类别 | 现有 | 新增 |
|------|------|------|
| 资产 | 6 个 | 其他货币资金/交易性金融资产/应收票据/预付账款/其他应收款/坏账准备/累计折旧/无形资产/累计摊销/长期股权投资/在建工程 等（约 30 个） |
| 负债 | 3 个 | 应付票据/预收账款/应交税费/其他应付款/长期借款/应付债券 等（约 15 个） |
| 权益 | 3 个 | 资本公积/盈余公积/库存股（约 6 个） |
| 成本 | 2 个 | 劳务成本/研发支出（约 4 个） |
| 损益 | 7 个 | 其他业务成本/投资收益/公允价值变动损益/资产减值损失/营业外收入/营业外支出/所得税费用/以前年度损益调整（约 15 个） |

#### 3.1.3 明细科目示例（二级）

| 一级科目 | 明细科目 |
|---------|---------|
| 1002 银行存款 | 100201 工商银行 / 100202 建设银行 |
| 2221 应交税费 | 222101 应交增值税 / 222102 应交所得税 |

### 3.2 辅助核算维度

#### 3.2.1 维度字典表 `auxiliary_dimension`

| 字段 | 类型 | 说明 |
|------|------|------|
| dimension_code | varchar(20) PK | 维度编码 |
| dimension_name | varchar(50) | 维度名称 |
| status | varchar(16) | ACTIVE |

预置 5 个维度：`DEPT`部门 / `PROJECT`项目 / `CUSTOMER`客户 / `SUPPLIER`供应商 / `CASH_FLOW`现金流量。

#### 3.2.2 维度值表 `auxiliary_value`

| 字段 | 类型 | 说明 |
|------|------|------|
| value_id | bigint PK | 自增 |
| dimension_code | varchar(20) | 所属维度 |
| value_code | varchar(50) | 值编码 |
| value_name | varchar(100) | 值名称 |
| status | varchar(16) | ACTIVE |

#### 3.2.3 分录行辅助核算关联表 `journal_entry_line_aux`

| 字段 | 类型 | 说明 |
|------|------|------|
| line_id | bigint | 分录行ID（复合主键） |
| dimension_code | varchar(20) | 维度编码（复合主键） |
| value_code | varchar(50) | 维度值编码 |

一条分录行可挂多个辅助核算维度（如：借方"管理费用"挂"部门=技术部"+"项目=研发A"）。

### 3.3 科目校验升级

- 分录录入时，subject_code 须在 account_subject 存在（现有 1004 校验）
- 辅助核算：挂载的 dimension_code 须在 auxiliary_dimension 存在，value_code 须在 auxiliary_value 存在

## 四、执行步骤

```
步骤1：扩展 account_subject 表（加 parent_code + subject_level）
步骤2：预置完整一级科目（21 → 80）+ 示例明细科目
步骤3：新建辅助核算 3 张表（维度/维度值/分录行关联）
步骤4：预置辅助核算维度 + 示例维度值
步骤5：分录录入接口支持辅助核算（EntryServiceImpl + DTO 改造）
步骤6：验证（科目层级查询 + 辅助核算分录录入）
```

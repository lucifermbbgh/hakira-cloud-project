## 三、验证要点

1. **两种折旧方法对比**：直线法月折旧 95 vs 双倍余额递减首月 200，验证加速折旧
   前期多提折旧的特性。

2. **折旧凭证自动入账**：计提生成「借 管理费用 / 贷 累计折旧」凭证，累计折旧与
   净值联动更新，乐观锁防并发重复计提。

3. **处置清理凭证**：借 累计折旧 + 借 营业外支出（净值）= 贷 固定资产（原值），
   借贷平衡，状态置 DISPOSED。
